# 🏋️ GymBro

### Your training. Your rhythm. Your progress.

GymBro is a premium, mobile-first workout and fitness tracking web application designed to feel like a native mobile fitness app.

The visual experience is inspired by the design language of Apple Music — dark surfaces, large typography, red accents, translucent floating navigation, smooth transitions, and immersive workout screens.

GymBro is intentionally built using **pure HTML, CSS, and Vanilla JavaScript**, with the entire core application contained inside a single `index.html` file.

---

## ✨ Features

### 🏠 Today's Workout

The home screen focuses on the most important question:

> **What am I doing today?**

The Today screen provides:

- Dynamic greeting
- Live date
- Live time
- Today's workout
- Target muscle groups
- Motivational messages
- Workout progress
- Exercise checklist
- Workout timer
- Weekly statistics
- Weekly activity
- Recent workout activity
